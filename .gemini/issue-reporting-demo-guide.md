# Issue Reporting - Quick Demo Guide

## 30-Second Demo Script

### Step 1: Show Existing Issues (10 seconds)
**Action**: Navigate to Knowledge Base → My Issues tab

**What to highlight**:
- Point out the three sample issues
- Show the color-coded importance badges:
  - 🔴 Red = High (ISS-003 - Payroll access)
  - 🟡 Yellow = Moderate (ISS-001 - AC issue)
  - 🔵 Blue = Low (ISS-002 - Typo)
- Point out the reporter info, department, and area on each card

**Script**:
> "Here's the issue tracking system. Notice how issues are color-coded by importance - red for high priority, yellow for moderate, and blue for low. Each issue shows who reported it, which department handles it, and the specific area affected."

### Step 2: Create New Issue (20 seconds)
**Action**: Tap "+ New Issue" button

**What to highlight**:
1. **Auto-filled section**: "See how my name and department are automatically filled"
2. **Issue Department**: Type "IT"
3. **Issue Area**: Type "WiFi Network - Floor 2"
4. **Description**: Type "WiFi connection keeps dropping every 10 minutes"
5. **Importance**: Tap "High" (watch it turn red)
6. **Submit**: Tap "Submit Issue Report"

**Script**:
> "Creating an issue is simple. My information is already filled in. I just specify which department should handle it, the exact area or system, describe the problem, and set the importance level. Let me report a WiFi issue... I'll mark it as high priority since it's affecting work. Submit, and done - it's now in the system."

### Step 3: Show New Issue (5 seconds)
**Action**: Scroll to see the newly created issue at the top

**What to highlight**:
- New issue appears immediately
- Shows all the information entered
- Has the red "High" badge
- Status is "Open"

**Script**:
> "And there it is - the IT department can now see this high-priority WiFi issue with all the details they need to fix it."

## Detailed Demo Flow (For Longer Presentations)

### Part 1: Understanding the Issue List (2 minutes)

1. **Navigate to My Issues tab**
   - Show the tab navigation
   - Explain "My Issues" shows issues you've reported

2. **Walk through an existing issue card**
   - Point to Issue ID (ISS-001)
   - Show importance badge (Moderate - Yellow)
   - Show status badge (Open)
   - Read reporter info: "Fuad Tasrim Hossain (Merchandising)"
   - Read department: "Facilities"
   - Read area: "Meeting Room - Floor 3"
   - Read description: Full AC problem description
   - Show report date

3. **Compare different importance levels**
   - Show ISS-003 (High - Red): Payroll access issue
   - Show ISS-001 (Moderate - Yellow): AC problem
   - Show ISS-002 (Low - Blue): Documentation typo
   - Explain when to use each level

4. **Show resolved vs open**
   - Point out ISS-002 has green "Resolved" badge
   - Others have yellow "Open" badge

### Part 2: Creating a New Issue (3 minutes)

1. **Open the form**
   - Tap "+ New Issue" button
   - Modal slides up from bottom
   - Show the clean, organized layout

2. **Explain auto-filled section**
   - "Reporter Information" section at top
   - Name: Automatically from your profile
   - Department: Automatically from your profile
   - "This ensures accountability and makes it easy to follow up"

3. **Fill Issue Department**
   - Tap the input field
   - Type "IT"
   - Explain: "This routes the issue to the right team"
   - Show placeholder examples

4. **Fill Specific Issue Area**
   - Tap the input field
   - Type "WiFi Network - Floor 2"
   - Explain: "Be specific so they know exactly where to look"
   - Show placeholder examples

5. **Fill Description**
   - Tap the text area
   - Type: "WiFi connection keeps dropping every 10 minutes. Started this morning around 9 AM. Affecting entire floor. Unable to access cloud systems."
   - Explain: "Include what, when, and impact"

6. **Select Importance**
   - Show all three options
   - Tap "Low" - watch it turn blue
   - Tap "Moderate" - watch it turn yellow
   - Tap "High" - watch it turn red
   - Explain each:
     - **Low**: "Minor issues, suggestions, can wait"
     - **Moderate**: "Normal priority, should be addressed soon"
     - **High**: "Urgent, affecting work, needs immediate attention"
   - Leave on "High" for this WiFi issue

7. **Submit**
   - Tap "Submit Issue Report"
   - Show validation (if you try to submit empty, it shows error)
   - Success message appears
   - Modal closes

8. **View the new issue**
   - Scroll to top of list
   - New issue appears with ID ISS-XXX
   - All information is displayed
   - Red "High" badge is visible
   - Status is "Open"

## Troubleshooting During Demo

**If form won't submit**:
- Check all required fields are filled
- Make sure description is not empty
- Verify department and area are specified

**If colors don't show**:
- Check device display settings
- Ensure proper lighting for visibility
- Zoom in if needed

**If keyboard covers input**:
- Scroll the form up
- Tap outside to dismiss keyboard
- Use device's keyboard hide button

## Questions & Answers

**Q: Can I attach photos to an issue?**
A: Not in this version, but it's a planned feature. For now, describe the issue in detail.

**Q: Who sees my reported issues?**
A: The department you specify, plus administrators. Your issues are also visible in your "My Issues" tab.

**Q: Can I edit an issue after submitting?**
A: Not currently. If you need to add information, you can report a follow-up issue or contact the department directly.

**Q: How do I know when my issue is resolved?**
A: The status badge will change from "Open" (yellow) to "Resolved" (green). In production, you'd also get a notification.

**Q: What if I don't know which department to assign?**
A: Use your best judgment. Common ones: IT (tech issues), Facilities (building/equipment), HR (policies/people), Safety (hazards).

**Q: Should I report urgent issues here or call someone?**
A: For true emergencies (fire, injury, security), call immediately. For urgent work issues, report here AND notify the relevant department.
