# E-Sign Quick Reference Card

## 🎯 Key Features at a Glance

### Color System
- 🔴 **Red** = Critical (due today/overdue)
- 🟡 **Yellow** = High (due in 1-3 days)
- 🟢 **Green** = Normal (4+ days)

### Tabs
- **To Sign** = Documents waiting for your signature
- **Sent** = Documents you created
- **Done** = All signatures completed
- **History** = Documents you've signed

### Signature Methods
- 👆 **Biometric** = Fingerprint authentication
- 📤 **Upload** = Upload signature image
- ✍️ **Draw** = Sign with stylus/finger

### Signing Orders
- **Sequential** = Must sign in order (1→2→3)
- **Parallel** = Everyone signs simultaneously

## 🎬 Quick Demo Flow

1. **Show urgency** → Point out red/yellow/green documents
2. **Search** → Type "Finance" or "November"
3. **Open document** → Show details and signers
4. **Sign** → Choose biometric method
5. **Create new** → Fill form, select signers
6. **History** → Show old documents

## 🔧 Troubleshooting

**Can't sign?**
- Check if sequential and not your turn
- Verify you haven't already signed

**Search not working?**
- Make sure search bar is open
- Try simpler terms

**Colors not showing?**
- Check deadline dates
- Verify display settings
